# بوت متجر تيليجرام (Telegram Shop Bot)

هيكل بوت كامل بنفس تجربة الاستخدام يلي بالصور: قائمة رئيسية، فئات ومنتجات، محفظة/رصيد، شحن عبر كريبتو
(BEP20 / TRC20 / Polygon / Binance Pay)، ملخص طلب وتأكيد شراء، مع لوحة موافقة للأدمن على طلبات الشحن.

## ملاحظة مهمة
المنتجات الموجودة بالكود (`bot/seed.py`) هي **placeholder فقط** (استشارة أمنية، تقرير Pentest)
لازم تبدّلها بمنتجاتك أو خدماتك الحقيقية قبل التشغيل الفعلي.

## خطوات التشغيل

1. ثبّت المكتبات:
   ```
   pip install -r requirements.txt --break-system-packages
   ```

2. اعمل نسخة عن ملف البيئة وعبّي بياناتك:
   ```
   cp .env.example .env
   ```
   وعدّل داخل `.env`:
   - `BOT_TOKEN`: التوكن من BotFather
   - `ADMIN_IDS`: آيدي حسابك على تيليجرام (لاستقبال إشعارات طلبات الشحن)
   - `WALLET_BEP20` / `WALLET_TRC20` / `WALLET_POLYGON`: عناوين محافظك الحقيقية

3. عبّي قاعدة البيانات بمنتجاتك (عدّل `bot/seed.py` أولًا بمنتجاتك الحقيقية، بعدين):
   ```
   python -m bot.seed
   ```

4. شغّل البوت:
   ```
   python main.py
   ```

## هيكلية المشروع

```
bot/
  config.py        # الإعدادات (توكن، أدمن، عناوين المحافظ)
  database.py       # طبقة قاعدة البيانات (SQLite عبر aiosqlite)
  keyboards.py       # كل لوحات الأزرار (Inline Keyboards)
  states.py          # حالات FSM (كمية مخصصة، إدخال مرجع الشحن)
  texts.py            # كل نصوص البوت بمكان واحد لسهولة التعديل
  seed.py              # تعبئة الفئات/المنتجات التجريبية
  handlers/
    menu.py            # القائمة الرئيسية + ملفي/سياسة/مساعدة/دعوات
    shop.py             # تصفح المنتجات + الشراء الكامل
    topup.py             # شحن الرصيد عبر الكريبتو
    admin.py              # موافقة/رفض الأدمن على طلبات الشحن
main.py                    # نقطة تشغيل البوت
```

## آلية شحن الرصيد (مهم أمنيًا)

بعكس أي بوت يدّعي "دفع تلقائي فوري" بدون تحقق حقيقي، هالبوت مبني على:
1. المستخدم يختار طريقة الدفع ويشوف العنوان/المعرف.
2. بعد التحويل الفعلي، يرسل هاش المعاملة أو رقم الطلب.
3. **الأدمن لازم يتحقق يدويًا** (من صفحة المحفظة أو Binance) قبل ما يضغط "موافقة" ويدخل المبلغ.
4. بس هيك بينزاف الرصيد لحساب المستخدم.

هاي الطريقة أبطأ شوي من "أوتوماتيك" لكنها الطريقة الآمنة والمسؤولة لتفادي:
- قبول تحويلات وهمية أو مزوّرة.
- التورط بغسيل أموال أو معاملات مشبوهة بدون رقابة.

إذا حابب تطور نظام دفع تلقائي حقيقي لاحقًا، الطريقة الصح هي ربط API فعلي لبوابة دفع (مثل NOWPayments أو
Binance Pay API الرسمي) يتحقق من المعاملة على البلوكتشين مباشرة، مش الاعتماد على المستخدم يرسل رقم ويصير
تصديق تلقائي أعمى.

## التخصيص

- بدّل نصوص `bot/texts.py` بأي صياغة تحبها.
- بدّل/زيد فئات ومنتجات فعلية عبر `bot/seed.py` أو ابني لوحة أدمن لإضافتها من داخل تيليجرام مباشرة.
- لو بدك تسليم رابط/كود تلقائي عند الشراء (delivery_type = link)، خزّنه بـ `delivery_content`
  وعدّل `shop.py -> confirm_order` ليتعامل معه حسب النوع.
